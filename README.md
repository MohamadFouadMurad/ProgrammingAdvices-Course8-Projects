# 📁 C++ Logic & Console Projects - Course 8

Welcome to my C++ projects repository! This showcase contains interactive, console-based applications developed to master algorithms, system design, object-oriented concepts, and advanced console architecture in C++.

---

## 📁 Included Projects

### 1. Project 1 - Bank Extension 2
An advanced iteration of the bank management system featuring a complete user management module, permission-based access control, transaction logging, and robust file-based persistence.

* **Tech Stack:** C++
* **Key Features:** Full user CRUD operations, granular permission management (bitwise access control), multi-user authentication, and transaction audit trails.
* **Source Code:** [Project 1 - Bank Extension 2](./01-Project%201%20-%20Bank%20Extention2.cpp)

---

### 2. Project 2 - ATM System
A complete simulation of an Automated Teller Machine (ATM) allowing verified users to perform standard banking operations independently through a secure PIN interface.

* **Tech Stack:** C++
* **Key Features:** User PIN authentication, quick withdraw, balance inquiry, custom withdraw/deposit limits, and direct account synchronization.
* **Source Code:** [Project 2 - ATM System](./02-Project%202%20-%20ATM%20System.cpp)

## 🛠️ How to Run

1. Open `ProgrammingAdvices-Course8-Projects.slnx` (or `.sln`) in Visual Studio.
2. Select the required `.cpp` file to run or build.
3. Compile using **C++11** or higher.
